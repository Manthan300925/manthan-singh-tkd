# Manthan Singh — Official Athlete Portfolio

Responsive static website built with HTML, CSS and vanilla JavaScript. No API keys or build step required.

## Preview
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy on Vercel
1. Extract this ZIP.
2. Upload the folder to GitHub and import the repository into Vercel (or deploy the folder with Vercel CLI).
3. Select **Other** as framework preset if asked.
4. Leave build command empty and use `.` as the output directory if Vercel asks for one.
5. Deploy.

## Important: set your domain
After choosing your final domain, replace every `YOUR-DOMAIN-HERE` occurrence in `index.html`, `robots.txt`, and `sitemap.xml` with the domain (no trailing slash), then redeploy.

## Included
- `index.html` — complete responsive portfolio
- `assets/manthan-portrait.webp` — supplied portrait
- `assets/manthan-competition.webp` — supplied competition photo
- `assets/favicon.svg`, `vercel.json`, `robots.txt`, `sitemap.xml`

The site intentionally omits the state name of the state-level gold medal, age and weight category. It uses only details supplied by Manthan. Google indexing or rankings cannot be guaranteed; after deployment, verify the domain in Google Search Console and submit the sitemap.
